Advanced Backend — 12 câu hỏi phỏng vấn thường gặp

Từ bài toán kinh điển “2 request cùng trừ tiền 1 tài khoản” cho tới idempotency, saga, queue, cache, index và API design. Mỗi câu hỏi là một trang riêng, kèm ví dụ code, so sánh thực tế và câu trả lời mẫu dùng được ngay khi phỏng vấn.

Mục lục

CÂU 01

Race Condition, Lock & Deadlock

Hai request cùng trừ tiền một tài khoản: khoảng hở đọc–ghi, pessimistic vs optimistic lock, và cách tránh deadlock.

 CÂU 02

Idempotency

User bấm thanh toán 2 lần do mạng chậm — idempotency key, unique constraint và retry an toàn.

 CÂU 03

Transaction xuyên service

Order – payment – inventory: saga, outbox pattern, compensation thay cho distributed transaction.

 CÂU 04

Queue & Async Processing

1000 request thanh toán cùng lúc: tách xử lý đồng bộ sang hàng đợi, worker, backpressure và retry.

 CÂU 05

Rate Limiting

Chặn spam rút tiền / đặt hàng: fixed window, sliding window, token bucket và nơi đặt rate limit.

 CÂU 06

Tối ưu Database & Query

Bảng transaction log hàng chục triệu row: index, partition, archive và cách đọc EXPLAIN.

 CÂU 07

Redis — khái niệm & case study

Redis dùng ở đâu trong dự án thật: cache, lock phân tán, rate limit, session và hàng đợi nhẹ.

 CÂU 08

Scalability & Pagination

API trả về 10.000 record: offset vs cursor-based pagination, chi phí thực tế của mỗi cách.

 CÂU 09

Index — cơ chế & đánh đổi

B-Tree hoạt động ra sao, composite index, và cái giá phải trả khi index quá nhiều.

 CÂU 10

Background Job

Khi nào tách tác vụ ra chạy nền thay vì xử lý ngay trong request, và cách đảm bảo job không mất.

 CÂU 11

Multi-tenant

Shared schema, schema riêng hay database riêng — chọn theo quy mô và yêu cầu cách ly dữ liệu.

 CÂU 12

API Design

REST vs GraphQL vs gRPC, versioning, idempotent method và chuẩn hoá format response / error.
