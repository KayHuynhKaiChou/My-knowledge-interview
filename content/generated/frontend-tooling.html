Refine

https://github.com/refinedev/refine

Refine là một React-based framework (hoặc gọi là meta-framework) giúp bạn:

  • Xây dựng nhanh chóng admin panel, dashboard, CMS, CRM, nội dung quản trị…
  • Quản lý data CRUD (Create, Read, Update, Delete) dễ dàng
  • Tích hợp sẵn với các UI framework: Ant Design, Material UI, Chakra UI, Tailwind CSS
  • Hỗ trợ data provider (REST, GraphQL, Supabase, Strapi, Hasura, Firebase…)
