Native module

  • là cầu nối giữa mã JavaScript của React Native và mã native (Android - Java/Kotlin, iOS - Swift/Objective-C).
  • các thư viện dùng trong react native đều được viết bằng Native Module, rồi đóng gói lại thành package npm

Gesture Responder System

Đây là hệ thống giúp React Native nhận biết và xử lý các cử chỉ của người dùng, ví dụ như:

  • Tap (chạm)
  • Swipe (vuốt)
  • Drag (kéo)
  • Pinch (chụm/mở hai ngón tay)

Công cụ dùng: react-native-gesture-handler , hay các hàm có sẵn ở View như <View

  onStartShouldSetResponder={() => true}

onResponderGrant={() => console.log('Bắt đầu chạm')}

onResponderMove={() => console.log('Đang kéo')}

onResponderRelease={() => console.log('Thả ra')}

>
