5 CSS

CSS sprite

CSS sprites combine multiple images into one single larger image. This would only require one server request resulting in a faster loading time. Without CSS sprites, each image will send out individual server requests.

Scale-y-0

giả sử có 1 div.container chứa 1 div.child , ban đầu height div.container = div.child = 100px , sau khi div.child đc set scale-y-0 thì div.child có height = 0px (theo kiểu visibility) , tuy nhiên thg div.container height vẫn = 100px; => scale-y-0 khác height:0px

11 CSS

white-space: 'break-spaces'

Đây là giá trị của white-space trong CSS, hoạt động gần giống pre-wrap nhưng có thêm:

  • Giữ nguyên khoảng trắng liên tiếp (nhiều dấu cách không bị gộp lại).
  • Tự động xuống dòng khi cần, giống pre-wrap.
  • Dòng dài vẫn được bẻ xuống, không tràn.
  • Tóm lại: → Giữ đúng khoảng trắng người dùng nhập, tab, enter... mà vẫn không làm vỡ layout.

tailwind

có 3 layers chính là base, component và utility

độ ưu tiên: base < component < utility => utility là có độ ưu tiên cao nhất

Tên Layer

Độ ưu tiên

Mục đích

Ví dụ

base

Thấp nhất

Dùng cho các thẻ HTML cơ bản (reset CSS), các style mặc định toàn trang.

h1, p, body, a...

components

Trung bình

Dùng cho các class phức tạp, tái sử dụng (UI components).

.btn, .card, .input-field...

utilities

Cao nhất

Dùng cho các class đơn lẻ, tiện ích. Luôn ghi đè được component và base.

.p-4, .text-center, .bg-red-500...
